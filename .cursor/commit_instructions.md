# 提交信息生成指南

> 本文档供 Cursor / AI 助手在生成提交信息（commit message、changes summary）时参考。

## 撰写要求
- **语言**：全部使用简体中文，可穿插英文专业名词，但整体表达应为中文句子。
- **语气**：专业、简洁，避免口语或过度夸张的修饰。
- **结构**：
  1. 第一行使用简短命令式语句描述主要变更，例如 `feat: 新增 VR 工具使用说明`
  2. 如需附加详情，使用 `-` 开头的中文条目列出，每条一句话，突出用户价值或技术要点。
- **术语**：Unity、VR、XR 等专有名词保持原文，其余描述尽量中文化，例如“配置”、“修复”、“优化”。
- **标点**：优先使用中文标点（，、。）；必要时可混用英文括号/斜杠。

## 示例
```
feat: 新增 VR 转换工具总览
- 在根目录 README 说明项目结构与环境要求
- 引导用户使用 Fire VR Converter 的一键转换流程
```

## 其他约定
- 若涉及 Bug 修复或 Breaking Change，请显式写明，例如“修复”、“兼容性调整”、“需要重新导入资源”等。
- 若无实质代码改动（如仅格式化），直接说明“仅格式整理”“更新说明文档”等。
- 遵循团队 Git 规范时，如需英文标签（feat/fix/chore），保留标签但描述依旧使用中文。
