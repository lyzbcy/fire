# 焦点卡顿优化助手

## 插件目标

焦点卡顿优化助手旨在降低 Unity 在外部脚本修改后重新获得焦点时的卡顿。插件会在编辑器失去焦点时暂停自动刷新，并在重新获得焦点后根据用户策略执行快速刷新、限流刷新或完全手动刷新，帮助团队掌控刷新节奏。

## 核心功能

- **多种刷新策略**：立即刷新、定时刷新、手动确认刷新自由切换。
- **可选 Enter Play Mode 优化**：一键开启/关闭跳过域重载、跳过场景重载等配置，并可在运行结束后自动恢复。
- **刷新耗时统计**：记录最近一次刷新耗时与触发方式，方便团队排查慢编译/慢导入。
- **安全模式**：默认不修改项目原有设置，所有选项均可独立开关。

## 安装

1. 保留 `Packages/com.fire.focusoptimizer` 于项目中，Unity 会自动识别为本地包。
2. 如需分发，可将该目录推送至独立 Git 仓库，并在 `manifest.json` 中通过 Git URL 引入。

## 使用方法

1. 在 Unity 顶部菜单中打开 `Tools/焦点卡顿优化助手`。
2. 根据团队协作需求选择刷新策略、限流时长与提示方式。
3. 如需加速进入 Play Mode，可在窗口中开启 Enter Play Mode 优化，并勾选需要跳过的阶段。
