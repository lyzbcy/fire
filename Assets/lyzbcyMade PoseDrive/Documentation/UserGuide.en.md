# PoseController User Guide

## 1. Quick Start

1. **Import Plugin**: Copy the `PoseController` folder to `Assets/`.
2. **Replace Models**: Copy real `movenet.onnx` and `action_classifier.onnx` files to `Runtime/Models/`.
3. **Run Quick Setup Wizard**: Open menu `Tools/PoseController/Setup Wizard`, select models and mappings, then click "Create/Update PoseController System" to automatically create WebCam + PoseDetector + ActionClassifier + PoseInputMapper + PoseControllerManager.
4. **Or Manual Setup**:
   - Drag sample scenes (`Samples~/ThirdPersonDemo/ThirdPersonDemo.unity` or `FirstPersonDemo/FirstPersonDemo.unity`), or
   - Place `PoseControllerSampleBootstrap` in any scene to automatically create runtime objects.
5. **Run**: Connect camera and enter Play Mode to see skeleton and action recognition.

## 2. Main Components

| Component | Purpose | How to Add Quickly |
| ---- | ---- | ---- |
| `WebcamProvider` | Initialize camera, provide texture frames | Auto-added by wizard |
| `PoseDetector` | Run MoveNet, generate `PoseData` | Auto-added by wizard, can bind model |
| `ActionClassifier` | Receive feature vectors, output gesture labels | Auto-added by wizard |
| `PoseControllerManager` | Feature extraction, action events, movement/view calculation | Auto-added by wizard |
| `PoseInputMapper` | Map gestures to virtual keys | Wizard can bind ScriptableObject |

All public APIs include XML documentation, viewable in your IDE.

## 3. Gesture → Key Mapping

1. Open menu `Tools/PoseController/Action Mapping`.
2. Select or create an `ActionMappingAsset`.
3. Configure `VirtualKey` (keyboard, mouse, or gamepad button) for each gesture.
4. Drag the asset to the `PoseInputMapper` component in your scene.
5. View real-time mapping status via `PoseControllerWindow` during Play Mode.

## 4. Adding/Removing Gestures

1. Add new labels to `ActionClassifier` training data and re-export `action_classifier.onnx`.
2. Add or adjust features in `PoseControllerManager.ExtractFeatureVector`.
3. Add corresponding gesture names in `PoseInputMapper` mapping asset.
4. (Optional) Add threshold-driven traditional gesture detection logic in `PoseControllerManager.DetectSimpleGestures`.

## 5. Importing New Models

1. Export ONNX using TensorFlow/TF Lite, PyTorch, etc.
2. Ensure input dimensions match the feature length generated by `PoseControllerManager`.
3. Replace files in `Runtime/Models` directory with the same names, or directly reference new TextAsset/NNModel in Inspector.
4. Run scene and check console debug output to confirm model loaded successfully.

## 6. Common Issues

- **Q: Will it error if no camera is available?**  
  A: No, `WebcamProvider` will fail gracefully and log to console. You can use recorded video or virtual camera instead.

- **Q: High latency?**  
  A: Reduce input resolution (`PoseDetector`'s `_inputWidth/_inputHeight`), disable debug logs, and use Burst/BLAS backend in Barracuda.

- **Q: How to switch gamepad buttons in built game?**  
  A: Call `PoseInputMapper.SetRuntimeBindings` at runtime to re-inject gesture mappings, or load different `ActionMappingAsset` at startup.

## 7. FAQ

| Issue | Suggestion |
| ---- | ---- |
| Camera image inverted | Correct via `WebCamTexture.videoRotationAngle`, or add flip in `PoseDetector` |
| Skeleton jitter | Adjust `_smoothing`, default 0.6, higher = more stable |
| Custom control logic | Subscribe to `PoseControllerManager.OnGestureTriggered`, or read `MoveVector`/`ViewDelta` to directly drive character |

Happy developing, enjoy the new motion control experience!
